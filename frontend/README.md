# AURA Control Plane — UX Contract

Implement a mobile-first control plane with these non-negotiable surfaces:

- **Today:** next meeting, source evidence labels, brief usefulness feedback, and “why am I seeing this?”
- **Focus:** Start/stop, selected duration, enabled signals, score explanation, suggested action, and immediate Undo.
- **Permissions:** per-source / per-action grants (Ask every time, This session, Always, Never); clear revoke and export/delete path.
- **Integrations:** connection health, exact Slack channel, device allowlist, and adapter capability/limitations.
- **Audit:** immutable action timeline with actor, policy, reason, result, and undo outcome; never display raw private transcripts by default.

Accessibility: screen-reader labels, visible focus state, high contrast, localized time zones, keyboard navigation, and no color-only status. Never render an employee leaderboard or manager view of a personal focus score.
